## Map

One graph per category and one for the crossings between them. One arrow per converter: solid for lossless, labeled for conditional, dotted for lossy; longer paths chain them. A stadium-shaped format has a converter into another category. A category whose pairs all go through a hub (image: every reader decodes to pixels, every writer encodes from them) draws the hub instead of every pair: an arrow in for each reader and out for each writer, styled by what that side loses. Under each graph, a grid gives every pair at a glance: ● lossless, ◐ conditional, ○ lossy, blank for no path, over one hop or several (the Paths table above has the notes).
