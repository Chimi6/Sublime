# Rich Text Format (rtf)

RTF is a tree of brace groups and control words over 8-bit text. Sublime
reads it into the document model (`src/io/rtf/reader.rs`) and writes the
model as RTF (`src/io/rtf/writer.rs`), so RTF reaches and is reached from
every document format: Word, Pages, Markdown, HTML, text, and PDF (out).
`src/io/rtf/lexer.rs` splits the source into tokens; `codepage.rs` holds the
single-byte code pages, generated by `scripts/gen-rtf-codepages.py`.

## Status

- `rtf -> docx`, `pages`, `markdown`, `html`, `text`, `pdf`: shipped.
- `docx`, `pages`, `markdown`, `html`, `text` `-> rtf`: shipped.

Measured with `scripts/rtf-check` on 88 Word documents (the repository's
fixtures and a corpus of real documents), each saved as RTF by LibreOffice
and by macOS (`textutil`, the Cocoa text system TextEdit uses):

| Path | Matches the reference's page count | Mean word recall |
|---|---|---|
| Word -> RTF (reference: the Word file) | ours 81, LibreOffice 81, Apple 65 | ours 0.969, LibreOffice 0.983, Apple 0.826 |
| LibreOffice RTF -> Word (reference: LibreOffice) | ours 84, Apple 57 | ours 0.971, Apple 0.945 |
| Cocoa RTF -> Word (reference: the macOS text system) | ours 80, Apple 75 | ours 0.893, Apple 0.892 |

Recall dips on a handful of files are rendering artifacts, not lost text:
shadowed and embossed text is drawn twice, wide letter spacing reads letter
by letter, and date and file-name fields are recomputed by LibreOffice.

Oracles (`tests/rtf_document.rs`): LibreOffice's RTF of nine fixture
sources reads to the same Markdown as the Word sources; Cocoa RTF reads to
its tables, lists, and text; a hand-written legacy file covers a Cyrillic
code page, old-style lists, a nested table, and Unicode escapes; and our own
RTF of every Word source reads back to the same Markdown (equations, written
as their text, aside).

## What is read and written

| Feature | RTF | Notes |
|---|---|---|
| Fonts, colours | `\fonttbl`, `\colortbl` | A font's `\fcharset` picks the code page of its `\'hh` bytes; Symbol and Wingdings bytes map to their private-use characters, and bullets among them to real bullets. |
| Text | text, `\'hh`, `\uN` with `\ucN` | Code pages 437, 850, 874, 1250-1258, and Mac Roman; surrogate pairs; the Asian double-byte pages only through `\uN` (Word always writes it). |
| Styles | `\stylesheet`, `\sN`, `\csN`, `\sbasedon` | Style 0 is the default; a paragraph naming no style is in it. Built-in heading names give outline levels where the writer left them out. |
| Character formatting | `\b \i \ul \strike \f \fs \cf \chcbpat \highlight \super \sub \up \dn \caps \scaps \v \lang \expndtw \charscalex` | Formatting in RTF is absolute: the reader keeps on a run only what differs from its paragraph's style, and gives text RTF's defaults where the style sets something the text does not. |
| Paragraph formatting | `\q* \li \ri \fi \sb \sa \sl \slmult \keepn \keep \widctlpar \outlinelevel \pagebb \contextualspace \cbpat \brdr* \tx` | |
| Lists | `\listtable`, `\listoverridetable`, `\lsN`, `\ilvlN`; old `\pn` | The writer gives each list instance its own override, so restarts and start numbers carry; the reader takes a list's start from its first item's rendered label (`\listtext`) when the definition disagrees (LibreOffice keeps a restart only there). |
| Tables | `\trowd \cellx \cell \row`, `\itap \nestcell \nestrow` | Rows with different edges share one grid; horizontal (`\clmgf`/`\clmrg`) and vertical (`\clvmgf`/`\clvmrg`) merges, borders, shading, vertical alignment, padding (Word writes left padding as `\clpadt` and top as `\clpadl`, and both sides keep that swap), header rows, row heights, nesting. |
| Sections | `\sectd \sect`, `\pgwsxn` and friends, `\cols \colsx \colw \colsr`, `\sbknone`, `\pgnrestart` | A section's last paragraph ends with `\sect`, as Word writes it; a `\par` there would add an empty paragraph. |
| Headers and footers | `\header \headerl \headerr \headerf` (and footers), `\titlepg \facingp` | |
| Fields | `\field \fldinst \fldrslt` | `HYPERLINK` (with `\l` anchors) becomes a link, `PAGE` and `NUMPAGES` live page fields; other fields keep their shown text. |
| Notes | `\chftn \footnote` | Endnotes read as footnotes (the model has no endnotes). |
| Comments | `\atrfstart \atrfend \atnid \atnauthor \atndate \annotation \atnref` | Replies carry `\atnparent`. |
| Tracked changes | `\revtbl \revised \deleted \revauth \revdttm` | Packed dates as ISO 8601. |
| Pictures | `\pict` (`\pngblip \jpegblip \emfblip \wmetafile \dibitmap`) | Hex or `\bin` data; goal size and scale; crops; the description (`\picprop` `wzDescription`) as alt text. A picture used twice is one picture. |
| Shapes | `\shp \shpinst \sp \shptxt` | Text boxes, filled rules and panels, preset geometry, and custom outlines (`pVerticies`, `pSegmentInfo`) both ways; behind-text and wrap. |
| Page colour | `\background` | |

## Writing

The writer writes the form Word writes, with `\htmautsp` and `\deftab` in
the header: LibreOffice spaces paragraphs by older rules without
`\htmautsp`, and a section break after a picture-only paragraph keeps a
`\par` before the `\sect` (LibreOffice otherwise loses that page break).

## Not carried

Equations (written as their text), charts, OLE objects (their result
picture is kept), drawn shapes with neither fill nor outline, form fields
(their shown text is kept), and text in double-byte code pages without
`\uN` escapes (each such character becomes U+FFFD). RTFD (TextEdit's
bundle of RTF and attachments) is a later step.
